Low-level C API

Zarrs.LibZarrs is a thin wrapper around the C API of the zarrs_jl Rust library. It is internal and may change between releases; use the high-level API instead.

The module is generated by gen/generator.jl from deps/zarrs_jl/zarrs_jl.h, which is itself generated from the Rust sources with cbindgen. After changing an extern "C" function in deps/zarrs_jl/src/, regenerate both files with Julia 1.13 (the version CI uses; gen/Manifest.toml pins the generator's dependencies):

cargo install cbindgen --version "$(cat gen/cbindgen-version)" --locked
julia --project=gen -e 'using Pkg; Pkg.instantiate()'
julia --project=gen gen/generator.jl

CI fails if the committed files do not match the regenerated output.
